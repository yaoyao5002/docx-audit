# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-08-20

- Add auditing for multiple DOCX files in one command.
- Add directory scanning and optional recursive scanning.
- Preserve the original single-file JSON output format while returning an array for batches.
- Add a `--version` flag.
- Expand tests and usage documentation.

## 0.1.0 - 2026-08-12

- Initial release with CJK, placeholder, explicit text-color, and WordprocessingML-part checks.
